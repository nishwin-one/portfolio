# Software engineering project demos

Three AI-assisted prototypes with local demos and tests. The examples use fictional data. Nothing is hosted or connected to real payment accounts.

| Project | What to try |
| --- | --- |
| [LedgerCheck](projects/ledgercheck) | Compare synthetic orders and payments. Check the JSON report or compare CSV output with the expected fixture. |
| [Webhook Relay](projects/webhook-relay) | Simulate a response timeout after an event is saved, restart the sender, and retry without saving a second receipt. |
| [Manipal Links](projects/manipal-links) | Open the offline demo or run an invite-only local server. Pair two test accounts and exchange a message after acceptance. This is not a live campus service. |

Each project has its own README with commands and limitations. Tests are run locally using those instructions; this branch does not deploy an app.
